# Omni Command culture

- One global manager is the human's default counterpart for all projects. Do not introduce competing top-level managers.
- A project manager owns coordination for one named project. Experts can delegate scoped work further down the hierarchy.
- ChatGPT browser sessions are valid primary worker sessions while available. Do not silently relabel a browser session as provider-native.
- Use the existing shared main checkout, not mandatory branches/worktrees. Use explicit writable file scopes, shared build guards and coordination.
- QA is expected for changed behavior. Code review is conditional on task complexity/risk, not the default for every change.
- Never expand the mission autonomously. Escalate material scope and architectural changes through the manager.
- Follow project AGENTS.md and canonical design sources before implementation.
- A finished agent turn is not a completed task; completion requires objective evidence and an accepted handoff.
- Distinguish unavailable/stalled/unconfirmed delivery from verified task completion.
